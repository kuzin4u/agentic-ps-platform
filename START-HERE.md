# Запуск: что сделать владельцу

Около 20 минут. После этого первая сессия в Claude Code идёт по плану из `docs/core/STATUS.md`.

## 1. Репозиторий на GitHub

Создайте открытый (Public) репозиторий `agentic-ps-platform` — README допустим, комплект его заменит. Видимость можно сменить позже в настройках репозитория.

## 2. Клон и распаковка

```bash
cd ~/repos
git clone https://github.com/<ваш-аккаунт>/agentic-ps-platform.git
cd agentic-ps-platform
git checkout -b claude-setup
# распакуйте архив так, чтобы содержимое папки agentic-ps-platform легло в корень клона
cp -R ~/Downloads/agentic-ps-platform/. .
git add -A
git commit -m "Комплект: документы, команды, хуки, CI"
git push -u origin claude-setup
```

Затем откройте Pull Request `claude-setup → main` и слейте его. CI должен быть зелёным: проверка каталога сценариев, типов и поиск секретов.

## 3. Защита ветки main

GitHub → Settings → Branches → правило для `main`: запрет прямых пушей, обязательный зелёный CI перед слиянием.

## 4. Песочница

С этапа 1 нужен Docker Desktop: песочница поднимается командой `docker compose up` (PostgreSQL и сервисы эмуляторов). Ключ модели не нужен — Платформа языковую модель не использует.

## 5. Проверка комплекта

```bash
cd ~/repos/agentic-ps-platform && claude
```

В Claude Code:
- `/check-setup` — ваша глобальная проверка комплекта;
- `/start` — начало первой сессии.

## 6. Решения до сессии 2

В `docs/core/DECISIONS.md` — РП1–РП12. Особенно важны:
- **РП1** — Платформа у оператора, процессинг вызывает её в пути авторизации;
- **РП2** — агент не инициирует авторизацию, а получает агентский реквизит и передаёт продавцу;
- **РП3** — режим «за эмитента» по умолчанию;
- **РП11** — резерв бюджета при авторизации, закрепление при клиринге.

## 7. Порядок работы двух репозиториев

Сначала этапы 1–2 Платформы, затем перевод BuyerAgent на ПАО. Изменение протокола — `/decision` здесь, затем `/decision` о переходе на версию в репозитории агента.

## Что защищено и как

| Что | Как |
|---|---|
| `git push`, создание и слияние PR | запрет в настройках + хук |
| `.env`, `*.pem`, `*.key` — чтение и запись | запрет в настройках + хук (в том числе `cat`, `grep`, `head` через Bash) |
| `docs/reference/` — запись | запрет в настройках + хук по цели записи (`>`, `>>`, `tee`, `sed -i`, `cp`/`mv` в этот путь); чтение разрешено |
| `.claude/hooks/` — правка самим Claude | хук |
| Ключ `sk-ant-`, приватный ключ, номер карты в коде | хук при записи + сканер в CI |
| Коммит, `npm install`, `curl` | спрашивает разрешения |

Ограничение: защита на стороне Claude Code не заменяет защиту ветки `main` на GitHub и хранение секретов вне репозитория.
