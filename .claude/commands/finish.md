---
Завершаем сессию. Перед `/exit` эта команда обязательна.

1. Прочитай `.claude/session-summary.md` (если есть) и `git diff --stat` от начала сессии.
2. Запусти `npm test` и `npm run scan:secrets`. Результаты — в отчёт.
3. Обнови `docs/core/STATUS.md`:
   - «Этап», «Последняя сессия» (дата, номер), «Сценарии: N из 28»;
   - раздел «Сделано» — что закрыто, со ссылками на коды задач и сценариев;
   - раздел «Расхождения» — всё найденное за сессию;
   - раздел «Следующая сессия» — заново: команда терминала, задачи с оценкой, контрольные точки, готовые сообщения `/task`, при необходимости `/decision`, и что за владельцем.
4. Обнови раздел «Точки сверки» в `docs/core/STATUS.md` по `docs/reference/joint-plan.md` (план «Россия»; задачи «Запада» — по `docs/reference/plan-west.md`): точка «пройдена» только при зелёном CI обоих репозиториев. В «Сделано» и «Следующей сессии» используй коды задач плана (PS-xx, AG-xx, CO-x). Задачи платформы, закрытые за сессию, назови в итоге: отметку «готово» в разделе «Ждём от платформы» агент ставит сам (окно А, Р-198); из окна Б — только комментарий к передаче (`gh issue comment N --repo kuzin4u/agentic-buyer-ref`) по «да» владельца; клон `../agentic-buyer-ref` не трогать (Р-714, Р-1019).
5. Сравни фактические часы с ROADMAP. Если этап сдвигается больше чем на одну сессию — предложи правку ROADMAP с строкой в журнал изменений и жди утверждения.
5а. Проверь ветку: `git rev-parse --abbrev-ref HEAD` — `task/*`, не `main`. Сверь таблицу «Кирпичи» в PR с `git log main..HEAD`: у каждого сделанного кирпича есть коммит, у каждого коммита, кроме «план:» и `/finish`, есть кирпич. Расхождения поправь в описании PR через `gh pr edit`.
6. Предложи текст коммита (на русском, с кодами задач) и жди команды «коммит». Коммит — только после «да» владельца; файлы — явно, без `git add -A`.
7. Сразу после коммита, без отдельного вопроса: push ветки `task/*` (отдельной командой) и проверка `git status -sb`. Ветка не впереди `origin`, в `docs/` нет ` M` и `??` — иначе сессия не закрыта: назови владельцу незакоммиченные файлы и не пиши «готово».
8. Итог для владельца — 5–8 строк: что сделано, что не сделано и почему, что проверить руками, что решить до следующей сессии; номер PR и статус CI. Слияние — владелец.
