description: Начало сессии — прочитать состояние и план, подтвердить задачи
---
Начинаем сессию работы над agentic-ps-platform.

1. Прочитай `CLAUDE.md`, затем `docs/core/STATUS.md` (раздел «Следующая сессия»), затем `docs/core/ROADMAP.md`.
2. Проверь рабочее состояние: `git status`, `git branch --show-current`, `git log --oneline -5`. Если есть незакоммиченные изменения — назови их и спроси, что с ними делать.
3. Обнови репозиторий агента: `git -C ../agentic-buyer-ref pull --ff-only`. Прочитай в `../agentic-buyer-ref/docs/core/STATUS.md` раздел «Ждём от платформы» — до выбора задач сессии. Задачи платформы, которых ждёт агент, ставь выше прочих при равной очерёдности по `docs/reference/joint-plan.md`.
4. Запусти `npm test` (если `node_modules` нет — попроси разрешения на `npm install`). Запиши результат.
5. Сверь план сессии с фактом: всё ли из предыдущей сессии сделано, нет ли новых записей в «Расхождениях».
6. Выведи коротко:
   - этап и номер сессии;
   - что ждёт агент (коды AG → PS из «Ждём от платформы»);
   - задачи сессии с оценкой времени;
   - контрольные точки;
   - что ты прочитаешь в нормах и ТЗ для первой задачи (конкретные пункты).
7. Жди «да» владельца. До «да» ничего не меняй.
