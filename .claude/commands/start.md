Начинаем сессию работы над agentic-ps-platform.

1. Прочитай `CLAUDE.md`, затем `docs/core/STATUS.md` (раздел «Следующая сессия»), затем `docs/core/ROADMAP.md`.
2. Проверь рабочее состояние: `git status`, `git rev-parse --abbrev-ref HEAD` (git 2.14 — `branch --show-current` нет), `git log --oneline -5`. Если есть незакоммиченные изменения — назови их и спроси, что с ними делать.
3. Прочитай раздел «Ждём от платформы» агента — только чтение, клон `../agentic-buyer-ref` не трогать (Р-714, Р-995, Р-1019): `gh api repos/kuzin4u/agentic-buyer-ref/contents/docs/core/STATUS.md --jq .content`, раскодировать base64 и взять раздел «Ждём от платформы»; состояние передач — `gh issue view N --repo kuzin4u/<репозиторий>`. До выбора задач сессии. Задачи платформы, которых ждёт агент, ставь выше прочих при равной очерёдности по `docs/reference/joint-plan.md`.
4. Запусти `npm test` (если `node_modules` нет — попроси разрешения на `npm install`). Запиши результат.
5. Сверь план сессии с фактом: всё ли из предыдущей сессии сделано, нет ли новых записей в «Расхождениях».
6. Выведи коротко:
   - этап и номер сессии;
   - что ждёт агент (коды AG → PS из «Ждём от платформы»);
   - задачи сессии с оценкой времени;
   - контрольные точки;
   - что ты прочитаешь в нормах и ТЗ для первой задачи (конкретные пункты).
7. Жди «да» владельца. До «да» ничего не меняй.
