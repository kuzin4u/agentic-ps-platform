# Сценарии приёмки Платформы

Источник истины — `tests/scenarios/scenarios.json`; таблица сгенерирована из него. Изменения — через `/decision`; тест `catalog.test.ts` проверяет совпадение.

Сценарии BuyerAgent (П01–П24, Д01–Д06) живут в его репозитории и прогоняются против песочницы Платформы — это критерий приёмки №6.
