# План продукта: Платформа платёжной системы

Редакция 1 · 08.10.2026. Корректируется по предложению Claude с утверждения владельца; изменения — в журнал внизу. Сессия — около 3 часов.

## Цель

Платформа и эмуляторы окружения в песочнице, на которых проходят 28 сценариев Платформы и 30 сценариев BuyerAgent по ПАО v1. Результат — комплект для разговора с оператором и банками: работающая точка решения в пути авторизации, измеренные задержки и параметры, контракты ПИ-1–ПИ-9 с таблицами соответствия под альбомы форматов.

## Связь с репозиторием BuyerAgent

| Этап Платформы | Что получает агент |
|---|---|
| 1 | Можно переводить стадии 0–1 агента на ПАО (мандаты с подписью в банке) |
| 3 | Агент переходит с `/v1/pay/*` на `/credentials` и события; контрактные тесты ПАО v1 |
| 4 | Сценарии П12 и Т7 — через страницу УПК |
| 6 | Приёмка агента против песочницы |

Рекомендуемый порядок: этапы 1–2 Платформы идут раньше этапов 2–3 агента. До этого агент работает на своём лёгком моке.

## Что за владельцем

- Подтвердить РП1–РП15 до сессии 2 — подтверждены 08.10.2026.
- Альбомы форматов ОПКЦ, СБП и токен-сервиса для адаптеров — запрос через банк-участника; без них ПИ остаются на канонической модели.
- Ключ модели здесь не нужен: Платформа языковую модель не использует.
