# План «Запад»: агент покупателя под брендом банка для ЕС, затем США

Редакция 1 · 14.10.2026 · Заменяет совместный план ред. 6–8 (источник правды по решению владельца 14.10.2026). Один из двух планов по рынкам (решение владельца 14.10.2026). Второй — **план «Россия»** (`docs/reference/joint-plan.md`), в нём общее ядро (инвариант), на которое опирается этот план. Общий календарь — раздел 1.

**Цель:** всерьёз закрепиться — агент для банков под их брендом (white-label), работа через Visa Intelligent Commerce и Mastercard Agent Pay; **MVP Запада (З1) ≈ 22.11**, демо банкам ЕС, **пилот с банком в ЕС — апрель 2027**. Позиционирование и конкурентное преимущество — документ «2026-10-14 Приоритеты рынков».

**Состав:** К5 (CO-К5, AG-К9, AG-К10, UI-К5, DOC-К4…К6) + валюты (CO-К6, AG-К11, PS-К3) + GDPR (AG-К12) + несколько платформ (AG-К5…К7, CO-К4, DOC-К3) + «лучше и дешевле» (AG-К2…К4, PS-К2, UI-К3, UI-К4) + шаги владельца OWN-1…4. Всего 26. Функции «лучше и дешевле» и архитектура нескольких платформ нужны и России — делаются здесь, используются обоими рынками.

**Правила совместимости (для обоих планов, проверяются на ревью каждого кирпича):** 1) агент работает с платформой только через порт; 2) сумма — пара «число в минимальных единицах + валюта», даже если пока только рубли; 3) экраны — с переключением языка и настройкой бренда с первого коммита. Что совпадает между рынками, что настраивается, дорабатывается или разрабатывается заново — документ решений, раздел 9.
