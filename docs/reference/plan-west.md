# План «Запад»: агент покупателя под брендом банка для ЕС, затем США

Редакция 4 · 16.10.2026 · Заменяет ред. 1 (14.10.2026). Второй план — **план «Россия»** (`docs/reference/joint-plan.md`), в нём общее ядро (инвариант) и этап запуска боевого контура (MVP). Список задач не менялся; задачи сгруппированы по этапам З1–З5, время — в часах.

**Цель:** всерьёз закрепиться — агент для банков под их брендом (white-label), работа через Visa Intelligent Commerce и Mastercard Agent Pay; MVP Запада, демо банкам ЕС, **пилот с банком в ЕС — апрель 2027**.
